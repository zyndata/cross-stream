# CrossStream Server

Bonding server for [CrossStream](https://github.com/zyndata/cross-stream) hubs: a hub
laptop bonds the mobile data of several phones into one encrypted tunnel to this
server and shares it as a Wi-Fi hotspot.

- Web panel in the Home Assistant sidebar (ingress, no extra login).
- Hubs enroll with a one-time code from the panel.
- Server identity and hub list are part of Home Assistant backups.

See the Documentation tab for the setup.
